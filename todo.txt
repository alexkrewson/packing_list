SUPABASE MIGRATION NEEDED (run in the Supabase SQL editor)
===========================================================
Added 2026-07-16: Pack tab switched from flat categories to nested containers,
and the master item/category library was reset. Run on the live DB:

ALTER TABLE public.master_items ALTER COLUMN cat_id DROP NOT NULL;
ALTER TABLE public.master_items ADD COLUMN IF NOT EXISTS container_id TEXT;
ALTER TABLE public.master_items ADD COLUMN IF NOT EXISTS order_index BIGINT;

CREATE TABLE IF NOT EXISTS public.master_containers (
  user_id     UUID   NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  id          TEXT   NOT NULL,
  name        TEXT   NOT NULL,
  icon        TEXT,
  parent_id   TEXT,
  order_index BIGINT NOT NULL DEFAULT 0,
  PRIMARY KEY (user_id, id)
);
ALTER TABLE public.master_containers ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users manage own master_containers"
  ON public.master_containers FOR ALL
  USING  (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);
CREATE INDEX IF NOT EXISTS master_containers_user_idx ON public.master_containers (user_id);

(schema.sql has already been updated to match — this is just the live-DB migration.
Until this runs, pack-tab container data won't sync to/from Supabase — the app
still works fully in local-only/localStorage terms.)
